## What the pi result contributes

For a quarter-circle grid, exact cell classification gives
`4Y/n² ≤ π ≤ 4(Y+M)/n²`. The proof bounds the cells containing both inside and
outside points by `M ≤ 3n`; hence the uncertainty width tends to zero. Their
shared curve explains why preserving their relation matters. Rational brackets
remain open at every finite stage, while a finite requested answer can be fully
certified.

This guides the working-state design: retain shared alternatives and evidence,
ask the task's question, refine useful open parts, preserve settled work, reopen
affected conclusions on correction, and extend into new questions. The exact
proof does not supply a learned controller. Choosing useful representations,
questions and transitions is part of the core that still needs trained evidence.

The original [trit-computer demonstration](../examples/trit-computer.html) is
included as a standalone HTML source. Opening it is user-controlled. Its pure
arithmetic has executable checks; browser interaction is separately unverified.

## Run a small real consumer first

Use Python 3.14 or newer, a C++20 compiler and OpenSSL development files.
`pkg-config` can supply OpenSSL, or set `NANOAI_OPENSSL_ROOT`. From the repository
root, in an environment you control:

```sh
python -m pip install ./packages/nanoai-tokens
python -m pip install .
python -m unittest discover -s tests -p 'test_relations.py' -v
python tools/verify_relational_math.py
python tools/verify_pi_refinement.py
```

The pi checker additionally needs Node.js for the shipped HTML's pure functions.
These paths require no neural model. The [catalogue example](catalogue.md) provides
another complete source/correction/recovery consumer. The README documents the
full suite and optional native dependency selectors. Skips name missing local
capabilities; they do not establish those capabilities.
