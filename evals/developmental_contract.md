# Developmental loop, frozen comparison 1

The user asks for a working path from words and contextual meanings through choices, consequences and learning. This experiment connects that path to the existing exact source, scratchboard, artifact and SJQL recovery owners. It measures a bounded reading-and-action learner. The destination remains the jointly trained byte/patch core and the complete requirements in the parent architecture.

The original Qwen3.5-2B BF16 instrument supplies all-layer causal last-token features in its native tokenizer. Original model words and F32 auxiliaries remain unchanged. The candidate jointly trains a byte encoder, a projection of all 2048 feature dimensions, a recurrent workspace, an evidence head and an action head in F32. No source matrix is cropped. Cached features identify the exact text, native token IDs, model manifest and worker implementation. A cache hit avoids repeated unchanged encoding; feature preparation counts in total cost.

The authored environment supplies short English and Turkish notices. Episodes contain a question, evidence, corrections, unrelated observations, conflict or missing information, and an editable-document action menu. Whole domain families are assigned to training, validation and evaluation before features or training. Candidate order is shuffled independently of the answer. Expected evidence labels and desired artifact content stay in the evaluator, outside learner inputs. These are bounded authored reading tasks, rather than general-language or personality qualification.

First a uniform behavior policy performs an actual local document action. Its selection probabilities, candidate set, source snapshot, receipt and independently read artifact bytes become an experience. The evaluator also exposes replayable exact menu targets from the frozen authored rubric, separately from the chosen action's observed outcome. Training consumes these checked experiences. Cross entropy trains the action head and three-channel evidence head together; there is no off-policy or world-truth claim.

Compare seeds 11, 23 and 37; an untrained head; a separately trained last-observation-only control; lexical retrieval over all observations; nearest training-episode retrieval using the same complete BF16 features; and the unchanged BF16 actor on the held-out menu. Each neural arm uses identical train/validation/evaluation families and candidates. Select epoch by validation action accuracy, with validation loss as tie break, never by evaluation outcomes. Maximum 300 epochs, AdamW, learning rate 0.002, batch size 24, gradient norm bound 1.0. Report seed results and per-mode failures. A corrective consolidation pass uses only designated training corrections plus replay, followed by repeated untouched evaluation and retention tasks.

Candidate admission requires at least 75% held-out complete-artifact success, no regression against its parent on the retained training/validation panel, and no critical journal, source, effect or recovery failure. Exceeding a control is reported only when measured. A failed candidate remains available for research without replacing the original resident instrument.

Recovery checks restore the exact candidate and F32 workspace, compare resumed scores with uninterrupted execution, invalidate numerical state after candidate/source changes, reconstruct experience from a fresh process, and reconcile an actual interruption between artifact publication and its receipt. Every source/manifest hash is checked. Native inference has a 120-second per-request, 7-GiB RSS and 512-MiB swap-growth guard; extraction has a 30-minute whole-run guard. Training has a five-minute guard, four CPU threads and no simultaneous native model. Report preparation, training, inference, publication, physical footprint and host swap separately.

Vocabulary learning is Claude's separately versioned owner. Its exact byte segmentation can be imported as a lexical witness; its likelihood and piece count do not establish contextual meaning. The new candidate has its own byte encoder and preserves the native pretrained tokenizer. Changing a vocabulary or feature basis requires a new candidate and state reconstruction.
